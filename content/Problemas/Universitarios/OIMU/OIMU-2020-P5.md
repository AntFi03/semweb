## Enunciado
  Sexa $x$ un número real. Para cada enteiro positivo $n\$, sexa $A_n$ a matriz $n \times n$ tal que $a_{ii} = x$, $a_{ij} = 1$ se $\abs{i-j} = 1\$ e $a_{ij} = 0$ se $|i-j| >1$. Probar que se o determinante de $A_n$ é positivo para todo enteiro positivo $n$, entón $x \geq 2$.

---

## Resolución
Sexa $d_n\) o determinante de $A_n\) para cada enteiro positivo $n\). Desarrollando o determinante pola primeira columna obtemos $d_{n+1} = xd_n - d_{n-1}\) para todo enteiro positivo $n\) (tómase por convención $d_0 = 1\) para que o anterior se cumpra con $n=1\)).
Temos $d_1 = x\). Se $d_1 > 0\) entón $x>0\). A recursión linear para $d_n\) danos unha fórmula do tipo $d_n = c_1 \alpha^{n} + c_2 \beta^{n}\) para todo $n \geq 0\), onde $\alpha\) e $\beta\) son as raíces da ecuación $Y^{2}-xY+1=0\). Si $0<x<2\), pódese escribir $x=2 \cos(\theta)\), para un certo $\theta \in (0, \pi/2)\), e as solucións da ecuación van ser $\alpha = e^{i \theta} = \cos(\theta)+i \sen(\theta)\) e $\beta = e^{-i \theta} = \cos(\theta)-i \sen(\theta)\), e entón $\alpha^{n} = e^{in \theta} = \cos(n\theta)+i \sen(n\theta)\) e $\beta^{n} = e^{-in \theta} = \cos(n\theta)-i \sen(n\theta)\), para certas constantes $b_1, b_2\). Como $d_0 = 1\) e $d_1 = x = 2\cos(\theta)\), debemos ter $b_1 = 1\) e $b_2 = \cos(\theta)/\sen(\theta)\), entón:
$$d_n = b_1 \cos(n \theta) + b_2 \sin(n \theta) = \frac{\sin(\theta)\cos(n \theta) + cos(\theta)\sin(n \theta)}{sin(\theta)} = \frac{\sin((n+1)\theta)}{\sin(\theta)}.$$
Como $\theta \in (0,\pi/2)\), existe un enteiro positivo $n\) tal que $\pi<(n+1) \theta < 2 \pi\), para o cal $d_n = \sen((n+1)\theta)/\sen(\theta)\), o que contradí a hipótese $d_n>0\), $\forall n\).
