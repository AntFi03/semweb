## Enunciado

Sexa $A\in\mathcal{M}_n(\mathbb{R})$ definida como $a_{ij}=(i+j)^2$. Calcula o determinante de $A$ en función de $n$.

---

## Resolución

 > [!solution2]- Solución
> Para $n=1,2,3$ claramente o determinante é distinto de 0. Para $n\geq 4$, $A=B+C+D$, onde os elementos destas matrices veñen dados por $b_{ij}=i^2$, $c_{ij}=j^2$ y $d_{ij}=2ij$. Así, tense que: $$\text{Rango } (A)=\text{ Rango } (B+C+D)\leq \text{ Rango } (B)+\text{ Rango } (C)+\text{ Rango } (D)=3,$$ logo o determinante de $A$ será 0 (empregouse a desigualdade para os rangos: $\text{Rango} (A+B)\leq \text{ Rango }(A)+\text { Rango } (B)$).
